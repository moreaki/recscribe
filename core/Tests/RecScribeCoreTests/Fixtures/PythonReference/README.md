# Frozen migration references

Captured locally on 2026-11-03 before retiring the Python implementation at
`b980bebb05b86661b6e078afe08f310de30c4868` (unchanged on branch commit `1172318`).
The capture ran all 44 native tests with the independent Python reference enabled
and passed. This directory preserves 16 synthetic cases / 80 output files.
`SHA256SUMS` records their original bytes, including intentional text whitespace.
No private recordings, transcripts, API credentials or model weights are included.

- `inspection-pcm-{8,16,24,32}`: Python inspection of deterministic 1,003-frame,
  44.1-kHz stereo fixtures spanning full-scale positive/negative samples and a
  per-channel difference. Swift tests compare metadata, SHA-256, exact channel
  windows and floating-point metrics (tolerance 1e-12).
- `audio-identical-normalize`, `audio-distinct-silent`, `audio-regions`,
  `audio-verified`, `audio-session-v{1,2,3}`: actual Python Job results using a
  clearly synthetic ASR adapter, deterministic PCM from AudioJobTests and FFmpeg
  preparation. Swift AudioJob compares source/segments/review/language/status
  semantics and five export files. No claim of resampler byte equality is made.
- `audio-missing`: native missing-part canonical result independently validated
  and rendered by Python. Localized filesystem error wording is not a runtime
  golden assertion. Explicit Swift assertions retain the missing gap and part
  boundaries; this frozen input independently checks validation/rendering.
- `text-{normalize-summary,summary-only,translate,cloud-normalize}`: native text
  jobs using synthetic provider responses, independently validated/rendered by
  Python. These check rendering, not a real provider or Python AI inference.

Canonical inputs replace temporary root paths with `/fixture`, job IDs with
`fixture`, processing start dates with `2026-01-01T00:00:00Z`, engine elapsed
seconds and processing elapsed milliseconds with zero. Source durations, PCM
hashes, offsets, channel identities, review reasons and Unicode text are retained.
Inspection paths are `/fixture/<synthetic filename>`. Exports are Python renderer
bytes from these stabilized inputs. Filesystem aliases were verified by identity
during capture. Raw audio remains generated by Swift tests, not checked in.

`GoldenReferenceTests` always validates the 12 canonical documents and compares
all five rendered files byte-for-byte. Audio/text job tests compare their newly
produced results to the same frozen expectations. Missing fixtures fail tests;
there is no environment-variable bypass or interpreter dependency. Schema copies
and negative semantic/cancellation/source-mutation tests remain independently
checked by the native suite.

Do not rebaseline expectations from the Swift implementation under test. A future
intentional contract change requires review of input/expected differences and
fixture provenance. The historical Python source can be recovered from Git if a
new independent reference capture is needed; it is not a runtime dependency.
