# Licensing RecScribe

RecScribe currently uses the Apache License 2.0 because its recording foundation is a
derivative of Home Rec, which is distributed under that license.

## Current repository policy

- `LICENSE` contains the unchanged Apache License 2.0 text.
- `NOTICE` retains the Home Rec copyright and attribution and adds RecScribe's notice.
- Modified files may carry RecScribe copyright notices without removing original
  copyright notices.
- Third-party components keep their own license and attribution requirements.

## If the project needs a different license

Apache 2.0 permits additional or different terms for original modifications and for a
derivative work as a whole, provided distribution still complies with Apache 2.0 for
the inherited code. In particular, the Apache license text, applicable copyright
notices, a readable copy of relevant `NOTICE` attributions, and notices of modified
files must be preserved.

Practical options include:

1. Keep the whole repository under Apache 2.0. This is the simplest current choice.
2. Dual-license RecScribe-owned additions while retaining Apache 2.0 for inherited
   Home Rec code.
3. Place clearly separated, entirely original components under another compatible
   license and document the boundary precisely.
4. Distribute a proprietary product containing the Apache-licensed foundation while
   continuing to satisfy Apache 2.0 attribution and notice obligations.

Do not replace `LICENSE` with another license and imply that the inherited Home Rec
code is no longer covered by Apache 2.0. Before adopting proprietary terms, a copyleft
license, or a custom license, obtain qualified legal advice and audit every bundled
dependency.
