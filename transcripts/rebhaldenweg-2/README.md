## Preparation

- Recording length: **1:51:02.741**. Timestamps refer to the original recording, including pauses; they are approximate speech-recognition timings.
- Prepared on **15 October 2026**. This is the preparation date, not an inferred date of the webinar.
- English: automatic local transcription with whisper.cpp and `large-v3-turbo`, with a second complete `small` model pass used for editorial spot checks. Obvious acronym, terminology, and recognition errors were edited for readability. This is a lightly edited transcript, not a certified verbatim record.
- Arabic: translated directly in ChatGPT from the edited English into Modern Standard Arabic, following the user's request to use ChatGPT. Earlier local model translation drafts were excluded. All 105 paragraph pairs, numerical readings, and uncertainty markers were checked. The translation has not received an independent human linguistic review.
- The original audio, working audio, raw recognition results, and processing logs were kept local. Only the transcript exports and their source metadata are included here.
